# 普通任务策略

团队主对话是制作主体。优先复用已有辅助对话；新建临时子代理仍属当前聊天；只有 `keepInCurrentChat=false` 才允许创建独立工作对话。`disableSubagents=true` 禁止新 spawn，核心工作由主对话完成。

并发不超过模型设置 `maxAgents` 与宿主上限的较小值。模型设置成功刷新后只使用 Codex 当前可见目录中的模型；读取失败时沿用未改写的正式设置。模型不可用时按最新名单尝试下一候选，每个候选最多一次。用户取消、权限拒绝和任务错误不换模。全部失败时报告并停止，不由主对话伪装成已执行。

该技能不维护或注入工厂项目记录，只使用团队精简模型和策略。只有用户明确要求软件工厂时才转入 `auto-factory`，不得因普通开发、关键词或“继续”自动转成工厂项目。开关切换只影响后续派发，不终止已有任务。

团队主对话负责核心调查、实现、测试和返修闭环；辅助子代理只处理明确的辅助项，返回必要 delta、checks、refs 与 block。主对话不把关键实现或验收外包给辅助，也不为了省上下文省略任务范围、验收或授权边界。原生 spawn 必须显式给 prompt/message、具体 model 和受支持的 thinking/effort；schema 错误重试保持同一参数包。`assignedModel` 只作历史记录且未核实；没有 usage 证据时不得宣称节省 token 或费用。

任务按 ability 和 priority 适配。渠道不可用时可换下一候选，每候选最多一次；能力不足导致同类返工时升级到更高的启用能力档，并受既有重试上限约束。辅助失败不改变团队主对话的制作责任；主对话继续完成核心实现和验收，辅助结果只作为输入，不把关键工作转交给弱模型或只凭摘要代替实际检查。
